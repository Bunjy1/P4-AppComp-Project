# Function Example Notebooks

This folder contains example notebooks with details of use for each of the functions created for the ACPP UML cleaning project.
Before using the package, it is suggested to download these notebooks and run them to better understand the operation of each function.
The functions are explicitly designed for 4DSTEM data, and will work using the relevant example files downloaded from the shared UofG P&A examples folder on Jupyter hub.
Certain functions may work with users' own data but this is not guaranteed, reformatting of data for use may be required, see individual function input requirements for more.
